# Introduction

## Definition and Basics
HTML is a standard markup language used for creating web pages. It creates structure on the web, from page layouts and paragraphs to links, tags, and attributes. According to Wikipedia, HTML is the standard markup language for documents designed to be displayed in a web browser. HTML works by using tags that tell browsers how to display the content, making it a standardized system for tagging text files.

## HTML Document Structure

## Elements and Attributes

For example, the `href` attribute is used to specify the URL of a link.
